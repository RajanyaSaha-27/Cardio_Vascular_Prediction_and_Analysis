# ❤️ Cardio Vascular Disease Prediction & Analysis

A Machine Learning project focused on predicting the likelihood of cardiovascular disease using patient health data. The project combines data analysis, visualization, and multiple ML models to provide accurate predictions and meaningful insights.

---

## 🚀 Overview

Cardiovascular diseases are among the leading causes of death globally. Early prediction can significantly improve prevention and treatment.

This project uses machine learning techniques to:
- Predict the presence of cardiovascular disease
- Analyze key contributing health factors
- Compare multiple ML models for best performance

---

## 🎯 Objectives

- Build a predictive model for cardiovascular disease detection  
- Perform Exploratory Data Analysis (EDA) to uncover patterns  
- Identify important features affecting heart health  
- Evaluate multiple ML algorithms and optimize performance  

---

## 🧠 Tech Stack

- **Language:** Python  
- **Libraries:**  
  - NumPy  
  - Pandas  
  - Matplotlib / Seaborn  
  - Scikit-learn  

---

## 📊 Dataset

- Contains patient health records such as:
  - Age  
  - Gender  
  - Blood Pressure  
  - Cholesterol  
  - Heart Rate  
  - Other clinical parameters  

- Used for classification:  
  👉 Disease Present / Not Present  

---

## 🔍 Project Workflow

1. **Data Preprocessing**
   - Handling missing values  
   - Encoding categorical data  
   - Feature scaling  

2. **Exploratory Data Analysis**
   - Correlation analysis  
   - Feature distribution  
   - Visualization of trends  

3. **Model Building**
   - K Nearest Neighbour 
   - Decision Tree  
   - Random Forest  

4. **Model Evaluation**
   - Accuracy  
   - Precision  
   - Recall  
   - F1-score  

---

## 📈 Results

- Compared multiple models to find best performance  
- Identified key health indicators influencing predictions  
- Achieved strong accuracy with optimized model  

---

## 💡 Key Insights

- Certain features like age, cholesterol, and blood pressure play a major role  
- Data preprocessing significantly improves model performance  
- Ensemble models generally perform better
